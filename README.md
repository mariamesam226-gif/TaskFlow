# TaskFlow

نظام لإدارة المهام تم تطويره باستخدام PHP وMariaDB.

## عن المشروع

TaskFlow هو تطبيق ويب بسيط يساعد المستخدم على تنظيم وإدارة مهامه اليومية.

يمكن للمستخدم إنشاء حساب، وتسجيل الدخول، ثم إدارة مهامه من خلال لوحة تحكم خاصة به.

## مميزات المشروع

- إنشاء حساب جديد
- تسجيل الدخول وتسجيل الخروج
- حماية كلمات المرور وتشفيرها
- إضافة مهام جديدة
- تغيير حالة المهمة
- حذف المهام
- لوحة تحكم خاصة بالمستخدم
- عرض إحصائيات المهام
- استخدام الجلسات لحماية صفحات المستخدم

## التقنيات المستخدمة

- PHP
- MariaDB
- MySQLi
- HTML
- CSS

## ملفات المشروع

- `index.php` — الصفحة الرئيسية وتحويل المستخدم للصفحة المناسبة
- `db.php` — الاتصال بقاعدة البيانات
- `register.php` — إنشاء حساب جديد
- `login.php` — تسجيل الدخول
- `tasks.php` — لوحة إدارة المهام

## الهدف من المشروع

تم إنشاء هذا المشروع لتطبيق مهارات PHP وقواعد البيانات، والتدرب على بناء نظام ويب متكامل يحتوي على تسجيل المستخدمين وإدارة البيانات وتنفيذ عمليات الإضافة والتعديل والحذف.
